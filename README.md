# Genetic Algorithm Optimization of Himmelblau’s Function

## 📌 Overview

This project focuses on implementing a Genetic Algorithm from scratch to study its behavior on a multimodal optimization problem. The emphasis is on understanding how different evolutionary operators influence convergence and solution quality.

---

## *Implementation Highlights*

* Developed a modular Genetic Algorithm framework in Python
* Implemented tournament selection for parent selection
* Designed custom crossover and mutation operators
* Represented solutions using real-valued encoding
* Tracked and visualized fitness progression across generations

---

##  *Results*

* Observed steady improvement in fitness over generations
* Convergence trends indicate effective exploration of the search space
* Performance varies based on parameter settings such as population size and mutation rate

---

##  *Future Enhancements*

* Incorporate elitism to retain high-quality solutions
* Improve mutation strategy for better local search
* Experiment with advanced crossover techniques
* Optimize hyperparameters for improved convergence
* Extend analysis with additional visualization and comparisons
